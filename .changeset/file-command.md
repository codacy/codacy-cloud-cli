New `file` command (alias `fl`): shows a file's grade, issues, complexity, duplication and coverage, its issues and clones, and its source code with a covered/not-covered gutter. Use `--lines <from-to>` to narrow the source or `--no-source` to hide it. With an auto-detected repository, the path can be relative to the current directory or absolute; a path outside the repository is refused.
